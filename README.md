## 🛠 Setup & Installation

1. Clone the repo:

   ```bash
   git clone https://github.com/your-username/shurk.git
   cd shurk
   ```
2. Install dependencies (example for front-end):

   ```bash
   cd frontend
   npm install
   ```
3. Configure environment variables (example `.env`):

   ```env
   REACT_APP_SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
   REACT_APP_TOKEN_MINT_ADDRESS=YOUR_TOKEN_MINT_ADDRESS
   ```
4. Build & run locally:

   ```bash
   npm run dev
   ```

   Or for the contracts:

   ```bash
   cd ../contract
   anchor build
   anchor deploy
   ```
